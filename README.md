# 📊 Business Report Summarizer

AI-powered tool that reads PDF business/financial reports and generates structured summaries — executive summary, financial highlights, key insights, risks, and overall assessment.

## Tech Stack
Python, Streamlit, Groq (Llama 3.3), PyMuPDF

## How to Run
1. `pip install streamlit groq python-dotenv pymupdf`
2. Add your Groq API key to a `.env` file: `GROQ_API_KEY=your_key`
3. `streamlit run app.py`
